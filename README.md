# Knight Moves Project - The Odin Project
This project is part of [The Odin Project](https://www.theodinproject.com) curriculum.
This project is designed to learn how to use data structures in a script.

## Launch the project
### Prerequisites: Install Node.js
- On Windows
```powershell
winget install OpenJS.NodeJS.LTS
```
- On Linux (Debian/Ubuntu)
```bash
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs
```
### Clone the repo:
- With URL
```bash
git clone https://github.com/Louis-dub/knights_travails_odin.git
```
- With SSH
```bash
git clone git@github.com:Louis-dub/knights_travails_odin.git
```
### Install dependencies
```bash
npm install
```
### Launch the project
```bash
node main.js
```
### Launch tests
```bash
npm test
```
## Technologies used
- **JavaScript**: To create the Node class, the Board class, and the knightMoves function
- **Jest 30**: To test my functions
- **Babel 7**: To transpile the code so it can be understood by Jest
